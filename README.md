# Family Work Schedule

A shared work schedule calendar designed to help family members coordinate their work schedules and plan the use of a shared car.

## About the Project

This is a personal project built as part of my hands-on learning in **AI-assisted software development**.

Instead of building the application entirely through traditional coding, I used AI coding tools throughout the development process to explore a modern AI-assisted development workflow — from turning a real-world problem into technical requirements, to generating code, debugging, refining the UI, and iterating on features.

The project is also an experiment in learning how to work effectively with AI coding agents while still making the architectural and product decisions myself.

## Current Features

* Shared calendar view for multiple users
* Add and manage users
* Individual work schedules for each user
* Recurring work schedule patterns
* Automatically generate calendar entries from recurring schedules
* View multiple users' schedules together
* Published as a working web application

### Example Recurring Schedule

Instead of entering every workday manually, users can define a pattern such as:

```text
Work: 4 days
Off: 4 days
Working hours: 7:00 AM – 7:00 PM
```

The application generates the corresponding schedule automatically on the calendar.

## Development Approach

This project follows an **AI-assisted coding workflow**:

1. Define the problem and requirements
2. Break the requirements into small development tasks
3. Use AI coding tools to implement features
4. Review and test the generated code
5. Identify and debug issues
6. Refine the implementation through iterative development

The goal is not simply to generate code with AI, but to develop the ability to **design, direct, review, and improve software using AI coding tools**.
